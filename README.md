# House Price Prediction 

## About the Project
This project explores house price prediction using Python and machine learning techniques.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Load and explore the housing dataset.
2. Perform data cleaning and preprocessing.
3. Visualize important features.
4. Train a machine learning model.
5. Evaluate the model's performance.
6. Predict house prices.

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open `Housing_prediction.ipynb` in Google Colab.
4. Run the cells in order.
